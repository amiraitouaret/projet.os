
# GIT VS GITHUB          


# GIT :
----
- Outil de gestion des versions.
- Fonctionne localement sur le PC.
- Suit les modifications du code.
- Permet de revenir aux anciennes versions.

# GITHUB :
-------
- Plateforme en ligne.
- Héberge les projets Git.
- Permet de partager et collaborer.
- Stocke les projets à distance.

# DIFFÉRENCE :
-----------
- Git = Gestion des versions.
- GitHub = Hébergement et partage du code.

# COMMANDES ESSENTIELLES :
-----------------------
- git init     : Initialiser un dépôt.
- git add .    : Ajouter les modifications.
- git commit   : Enregistrer les modifications.
- git push     : Envoyer vers GitHub.
- mkdir nom_dossier  : Créer un nouveau dossier.
- cd nom_dossier     : Entrer dans un dossier..
